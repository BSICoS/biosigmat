# Biosigmat v0.1.0

Biosigmat v0.1.0 is the first reproducible pre-1.0 release of the MATLAB
implementation. It is tested with MATLAB R2025a, Signal Processing Toolbox,
and Curve Fitting Toolbox.

The release is conformant with all eight specifications in Biosiglib v1.0.0,
pinned exactly to commit `ea2d5ded43e1348342f0db4fbd97d754b90a28c9`:

- `ecg.pantompkins`
- `ecg.sloperange`
- `hrv.tdmetrics`
- `tools.lpd_filter`
- `tools.medfilt_threshold`
- `tools.nan_filter`
- `tools.nan_filtfilt`
- `tools.snap_to_peak`

The release assets contain the exact reviewed source as
`biosigmat-0.1.0.zip` and `SHA256SUMS`. MATLAB File Exchange and `.mltbx`
distribution remain outside this release.
