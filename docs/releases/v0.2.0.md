# Biosigmat v0.2.0

Biosigmat v0.2.0 is a compatible pre-1.0 feature release of the MATLAB
implementation. It is tested with MATLAB R2025a, Signal Processing Toolbox,
and Curve Fitting Toolbox.

The release is conformant with all ten specifications in Biosiglib v1.2.1,
pinned exactly to commit `050a0527741415d4099ed6e2d8ba873fc76cf577`:

- `ecg.pantompkins`
- `ecg.sloperange`
- `hrv.fillgaps`
- `hrv.removefp`
- `hrv.tdmetrics`
- `tools.lpd_filter`
- `tools.medfilt_threshold`
- `tools.nan_filter`
- `tools.nan_filtfilt`
- `tools.snap_to_peak`

This release makes `removefp` and `fillgaps` conformant with the shared
contracts while preserving explicit preprocessing and the iterative MATLAB
workflow. `fillgaps` retains its interactive attempt-by-attempt debug view,
adds configurable empirical thresholds, and preserves unresolved timestamps
with aligned `NaN` intervals.

The release assets contain the exact reviewed source as
`biosigmat-0.2.0.zip` and `SHA256SUMS`. MATLAB File Exchange and `.mltbx`
distribution remain outside this release.
